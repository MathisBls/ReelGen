# SaaS Shorts IA - Workflows API & Cahier des charges (v1)

## Objectif

Construire une application SaaS permettant de transformer des vios longues en shorts (TikTok/YouTube/Instagram), avec pipeline IA (tection des moments forts, sous-titres, habillage), gestion multi-comptes, planification et publication via APIs officielles.

---

## 1) Personas & Cas d'usage

* **Cateur solo** : veut uploader un podcast/zoom, rer 10-20 extraits, valider, planifier.
* **Agencequipe** : veut connecter 10-50 comptes, traiter en batch, guer validation, suivre analytics.

---

## 2) Architecture Logique (high level)

**Frontend (Next.js/React)**

* UI d'upload,diteur de cut timeline, sous-titres WYSIWYG, gestion planning, analytics.

**Backend API (FastAPI Python ou Node.js/NestJS)**

* Services : Auth, Users/Teams, Media, Clips, Publish, Schedules, Analytics, Billing.

**Workers (queue)**

* Celery/RQ (Python) ou BullMQ (Node) pour jobs longs : transcription, tection, rendu, upload, publication.

**Stockage**

* Objets : S3/R2 pour vios/exports/thumbnails.
* DB : PostgreSQL (users, tokens OAuth, dias, jobs, posts, triques).
* Cache : Redis (sessions, queues, rate-limit, locks de publication).

**Ingrations**

* IA Speech-to-text : Whisper (open-source) ou service  (AssemblyAI, Deepgram).
* LLM/NLP : scoring moments forts, titres, descriptions, hashtags.
* Rendering : FFmpeg + librairie de templates (overlay, progress bar, waveforms).
* Plateformes : TikTok Open API (approue), YouTube Data API v3, Instagram Graph API.

## 6) curi, Compliance & Fiabili

* **OAuth** officiel par plateforme, **pas** de cation auto de comptes.
* Chiffrement au repos (KMS) des tokens, rotation & refresh automatiques.
* Rate-limit par utilisateur + backoff exponentiel, idempotency keys.
* File d'attente durable (Redis/RabbitMQ), retry policy, DLQ.
* Sanitisation inputs, analyse antivirus (ClamAV) sur upload.
* Logs structus + tra (OpenTelemetry), dashboards (Grafana).

---

## 7) Quali vio & Rendu (guidelines)

* Input recomman : 1080p, 25-60fps, H.264.
* Sorties : 1080x1920 (9:16), 1080x1080 (1:1), 1920x1080 (16:9), bitrate cible 8-12 Mbps.
* Safe zones texte (TikTok/IG UI) + marges.
* LUTs optionnelles, normalisation loudness (-14 LUFS pour shorts), ducking musique.

---

## 8) Templates & Sous-titres (format)

* **Subtitle JSON** (par mot) : `{ t0, t1, text, speaker? }`.
* Styles : police, taille, stroke, fond, animations (per-word reveal).
* **Templates** : JSON paratrable (couleurs, positions, assets, CTA).
